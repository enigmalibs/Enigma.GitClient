- **Where the icon lives** (unchanged since FEATURE-F7B5 / FEATURE-5096):

    `app.ico` copied beside the executable;
  - `src/Enigma.GitClient.Desktop/Assets/app-256.png`: the About dialog's image, the `.ico`'s 256 frame
    byte for byte;
  - `packaging/icon/enigma-git-client.svg`, `enigma-git-client-small.svg`: the masters;
  - `packaging/linux/icons/enigma-git-client-{16,24,32,48,64,96,128,256}.png`: what `install.sh`
    installs (`ICON_SIZES`).
- `AppIconTests` (Desktop tests) pins the frames, the About copy, the Linux copies and the output copy.
