## Objective

Replace the application icon with the new set in `C:\Dev\EnigmaLibs\Branding\Apps\final3\git-client`
(`.ico`, ten PNG frames, two SVG masters). Update every place the repository carries it:

- the executable's icon and the windows' icon (taskbar and title bar);
- the About dialog's image;
- the Linux installer's icons;
- the SVG masters.

## Context & constraints

- **The new artwork** is FEATURE-35EB's drawing (a line of commits and a branch, *Soft* palette: blue
  `#6A9BF4`, green `#63C77D`, transparent background) **scaled to fill the frame**. The large master
  wraps the `final2` paths in `translate(-31.2889 -31.2889) scale(1.2444)`, so the longest side spans 16
  to 240 of the 256-unit view box. The small master is redrawn on the same 16 to 240 live area, its
  straight edges on the 16-unit grid. Generated by `Branding/Apps/export.py final3`, which the SVGs'
  header comments name.
- **The new `.ico`** holds the same ten 32-bit RGBA PNG frames as today (16, 20, 24, 32, 40, 48, 64, 96,
  128, 256). Each frame is byte for byte the matching `png/enigma-git-client-N.png` (checked while
  planning).
- **Where the icon lives** (unchanged since FEATURE-F7B5 / FEATURE-5096 / FEATURE-35EB):
  - `src/Enigma.GitClient.Desktop/Assets/app.ico`: the `ApplicationIcon`, the `Icon` of `MainWindow` and
    `StartWindow`, and the `app.ico` copied beside the executable, which the MSI's shortcuts and
    control-panel entry use (`buildmsi.ps1`);
  - `src/Enigma.GitClient.Desktop/Assets/app-256.png`: the About dialog's image, the `.ico`'s 256 frame
    byte for byte;
  - `packaging/icon/enigma-git-client.svg`, `enigma-git-client-small.svg`: the masters;
  - `packaging/linux/icons/enigma-git-client-{16,24,32,48,64,96,128,256}.png`: what `install.sh`
    installs (`ICON_SIZES`).
- `AppIconTests` (Desktop tests) pins the frames, the About copy, the Linux copies and the output copy.
  Desktop tests are compiled but not run on this Windows machine (the user's standing rule). A script
  reproduces their assertions instead.
- The source directory is outside the repository and is left in place.
