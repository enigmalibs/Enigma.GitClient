# FEATURE-F7B5 — New application icon

**Status:** TODO
**Type:** FEATURE
**Branch:** `feature/feature-f7b5-new-app-icon`
**Run:** feature/2026-10-28-new-app-icon

## Objective

Replace the application icon with the new set dropped in `new-icons-remove-when-done/` (`.ico`, ten PNG
frames, two SVG masters), everywhere the repository carries it, then delete that temporary directory.

## Context & constraints

- **The new artwork** is the same drawing — a line of commits and a branch on a dark rounded square —
  in the *Soft* palette: blue `#6A9BF4` and green `#63C77D` instead of `#3574F0` and `#3FB950`. It is
  generated by the sibling `Branding` repository (`Branding/Apps/export.py`, GC-A2), which writes the
  SVGs, the PNG frames and the `.ico`.
- **The new `.ico`** holds ten 32-bit PNG frames — 16, 20, 24, 32, 40, 48, 64, 96, 128, 256 — each
  byte for byte the matching `enigma-git-client-N.png`. The current `app.ico` holds six (16, 32, 48, 64,
  128, 256). The 16 to 32 px frames come from `enigma-git-client-small.svg`, the 40 px and larger ones
  from `enigma-git-client.svg`.
- **Where the icon lives today:**
  - `src/Enigma.GitClient.Desktop/Assets/app.ico` — the `ApplicationIcon` and the windows' `Icon`;
  - `src/Enigma.GitClient.Desktop/Assets/app-256.png` — the splash and the About dialog, the `.ico`'s
    256 frame byte for byte (`AppIconTests` pins it);
  - `packaging/icon/enigma-git-client.svg`, `enigma-git-client-small.svg` — the masters;
  - `packaging/linux/icons/enigma-git-client-N.png` — installed by `install.sh` into
    `hicolor/<N>x<N>/apps`, removed by `uninstall.sh`, both from their own `ICON_SIZES` list.
- **hicolor** has `24x24` and `96x96` directories but none for 20 or 40 (Windows' 125 % sizes).
- `AppIconTests.TheIcon_HoldsSixSquare32BitPngFramesFrom16To256` pins the six sizes.
- The application's accent colours (`Themes/Graph.axaml`, `#3574F0`) are the UI's, not the icon's.

## Steps

1. Copy, byte for byte:
   - `enigma-git-client.ico` → `src/Enigma.GitClient.Desktop/Assets/app.ico`;
   - `enigma-git-client-256.png` → `src/Enigma.GitClient.Desktop/Assets/app-256.png`;
   - the two SVGs → `packaging/icon/`;
   - the 16, 24, 32, 48, 64, 96, 128 and 256 PNGs → `packaging/linux/icons/`.
2. `install.sh` and `uninstall.sh`: `ICON_SIZES=(16 24 32 48 64 96 128 256)`; their comments and help
   say eight icons, not six.
3. `README.md` and `docs/RELEASE.md`: the installed icon comes in eight sizes.
4. `AppIconTests`:
   - the frame test expects the ten sizes;
   - a new test: every size `install.sh` installs has its PNG in `packaging/linux/icons`, byte for
     byte the `.ico`'s frame of that size, and `uninstall.sh` lists the same sizes;
   - the class comment matches (ten frames, the export tool, the Linux copies pinned).
5. Delete `new-icons-remove-when-done/` (untracked: it never enters git).

## Acceptance criteria

- The four destinations hold the new files byte for byte; the old six-frame icon is gone.
- `install.sh` and `uninstall.sh` agree on eight sizes, each with its PNG.
- `AppIconTests` pins the ten frames, the splash copy and the Linux copies; the whole suite is green and
  the Release build has zero warnings.
- `new-icons-remove-when-done/` no longer exists.

## Out of scope

- The application's own accent colours.
- The 20 and 40 px PNGs as Linux icons (no hicolor directory for them; they ship inside the `.ico`).
- The version and the release notes (FEATURE-5736).
